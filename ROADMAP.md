# Pipe Layout Pro Roadmap

This roadmap describes current priorities and likely future direction. It is not a promise of release dates; field feedback and stability come first.

## v1.0 — Production launch

- [x] Trunnion layout calculator
- [x] 45° branch layout calculator
- [x] 90° branch layout calculator
- [x] Miter calculator
- [x] Saddle layout calculator
- [x] Imperial and metric measurements
- [x] Saved calculations/projects
- [x] Offline operation
- [ ] Confirm public Google Play production release
- [ ] Add public Play Store link to README
- [ ] Collect first production-user feedback
- [ ] Resolve launch bugs and device-specific issues

## v1.x — Improve the field workflow

Priorities will be driven by actual users. Likely areas include:

- Faster input and repeat calculations
- Clearer result presentation
- Better saved-project organization
- Additional share/export options
- Expanded pipe-size support
- Accessibility and readability improvements
- Additional layout calculators requested by tradespeople

## Future Pro direction

The current plan is to keep the initial core app useful and ad-free while exploring an optional one-time Pro upgrade rather than forcing a recurring subscription.

Potential Pro functionality includes:

- PDF cut sheets
- Unlimited saved layouts/projects
- Larger pipe-size ranges
- Advanced calculators and fabrication tools

These items may change based on technical feasibility and user feedback.
