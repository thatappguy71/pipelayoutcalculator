# Pipe Layout Pro Support

## Bug reports and feature requests

Use GitHub Issues:

https://github.com/thatappguy71/pipelayoutcalculator/issues

Choose **Bug report** for something that is not working correctly or appears to calculate incorrectly.

Choose **Feature request** for a new calculator, workflow improvement, or other enhancement.

## Before reporting a calculation problem

Please record:

- App version
- Device and Android version
- Calculator being used
- Imperial or Metric mode
- Exact input values
- Actual result
- Expected result and how you verified it
