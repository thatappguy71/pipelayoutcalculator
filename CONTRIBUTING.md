# Contributing to Pipe Layout Pro

Thanks for wanting to help improve Pipe Layout Pro.

## Current contribution model

The complete app source code is not currently published in this repository, so code pull requests are not being accepted at this time.

The most useful contributions right now are:

- Reproducible bug reports
- Calculation verification and edge cases
- Feature requests based on real fabrication workflows
- Device compatibility reports
- Documentation corrections
- Usability feedback from pipefitters, welders, fabricators, and apprentices

## Reporting a calculation issue

Please include enough information to reproduce the result:

1. Calculator used
2. App version
3. Measurement system (Imperial or Metric)
4. All input values
5. Result produced by the app
6. Result you expected
7. How you verified the expected result
8. Screenshot, if helpful

Do not include confidential customer drawings, proprietary project information, personal information, or employer-sensitive material.

## Feature requests

Good feature requests explain the field problem first and the proposed feature second. Describe when the calculation is used, what is slow or error-prone today, and what output would be most useful on the job.

## Safety

Never rely on an unverified issue comment as fabrication or engineering direction. Confirm work against applicable drawings, specifications, codes, procedures, and qualified engineering requirements.
